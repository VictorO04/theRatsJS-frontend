## Sobre o Projeto
Este projeto é fruto da integração entre as disciplinas de **Desenvolvimento de Sistemas (SENAI)** e **Língua Portuguesa/Inglês (SESI)**. Trata-se de uma plataforma digital colaborativa focada no estudo de obras literárias essenciais para vestibulares.

O foco da nossa equipe é a obra: **Os Ratos**.

A plataforma é totalmente bilíngue (Português/Inglês), com traduções adaptadas manualmente para garantir a fidelidade acadêmica e literária.

- Javascript
- Css
- ViteJs

## Como acessar o nosso site localmente

Primeiro, clone o repositório na sua máquina local

``` bash
git clone https://github.com/VictorO04/theRatsJS-frontend
```

Após clonar, instale as dependências.

``` bash
npm install
```

E por último, inicie o servidor localmente em `https://localhost:5174/` 

```bash
npm run dev
```
## Como acessar sem clonar localmente

Para acessar o nosso site sem clonar o repositório, basta entrar em:

> https://the-rats-js.vercel.app/
